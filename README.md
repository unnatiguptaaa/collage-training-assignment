# MicroNotes Assignment

A simple MERN-style Notes application built using React and Express.js.

## Features
- Add Notes
- View Notes
- REST API using Express
- React Frontend
- Async/Await with Fetch API

## Project Structure

```
micro-notes/
├── client/
├── server/
├── warmup.js
├── README.md
└── .gitignore
```

## Technologies Used
- React
- Vite
- Express.js
- JavaScript
- Node.js

## Installation

### Backend
```bash
cd server
npm install
npm start
```

### Frontend
```bash
cd client
npm install
npm run dev
```
